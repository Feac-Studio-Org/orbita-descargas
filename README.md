# Órbita · Descargas

Instaladores de Órbita, la plataforma de FEAC Estudio para organizar tu vida personal, tus proyectos y tus equipos.

Descárgalos en https://orbita-feac.vercel.app/descargar o en **Releases**.

- **Windows:** Orbita-Windows-Instalador.exe. Si sale "Windows protegió tu PC": Más información, luego Ejecutar de todas formas.
- **Mac:** Orbita-Mac.dmg. La primera vez: clic derecho sobre Órbita, luego Abrir.
- **Linux:** Orbita-linux-x86_64.AppImage. Dale permiso de ejecución y ábrelo.

Este repositorio solo publica los instaladores; el código es privado.
